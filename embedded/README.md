# Arduino embedded sketches

Pin assignments for the sketches in this folder:

| Pin | Sensor | Use |
| --- | --- | --- |
| 4 | TDS | Analog sensor output |
| 5 | Water level | Assigned pin; water-level reading is not implemented in these sketches yet |
| 6 | Temperature | DS18B20 data line |

These assignments apply to the standalone sketches in this folder.
