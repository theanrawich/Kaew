## PR review corrections

GPIO43/44 are now reserved unconditionally as UART0 console pins, for both pump and E-stop assignments. Compile-only host fixtures use inert Arduino/GPIO stubs with otherwise valid commissioning flags: the default-disabled and non-console positive controls compile; all four console-pin assignments fail with the expected reserved-pin assertion. These fixtures exercise the actual header; they neither select real hardware pins nor flash/run an enabled pump image.

Packet capture now requires a zero `trace_dropped` closing diagnostic from **each** board at/after the fixed `window + recovery` endpoint. Live capture waits up to 3 additional seconds (configurable) for these counters, without extending the PDR interval. Missing counters or nonzero counts reject the run; old saved logs lacking final counters must be recaptured. Host/USB buffering and unobserved board resets still require independent log-completeness checks; this is not proof against all logging loss.
